# NG Exhaustion Chain Phase 2 — Recurring Module Novelty Screen — 2026-08-18

Status: **NEW INDEPENDENT MODULES FOUND; RESEARCH CANDIDATE QUEUE ONLY; NO PLAY PROMOTION.**

This pass answers a specific finalization question: after removing every current event that already belongs to the trusted SSOS paper setup or the prioritized P-O-X-opposite setup, do other repeating chain groupings still carry stable behavior, or are they only renamed versions of what we already know?

They do. The remaining population contains a separate recurrence layer.

## Method boundary

- Same frozen 54-week canonical base plus insert-only held week.
- Same h=60 predecessor causal-availability wall.
- Same endpoint+5 entry / endpoint+60 descriptive return for this atlas screen.
- Absolute UP/DOWN is normalized; `SAME` / `FLIP` refers to current exhaustion polarity relative to the latest predecessor.
- Every current event that qualifies as trusted SSOS or P-O-X-opposite is removed from the **unique** screen.
- `WITH_CURRENT` means the observed oriented continuation sign is with current exhaustion polarity.
- `AGAINST_CURRENT` means the repeatable sign is opposite current exhaustion polarity. This is structural orientation only; it is not a frozen reversal trade.
- Week-relative deltas compare each module with the causally eligible non-trusted universe at the same predecessor depth and orientation.
- This is a many-pattern exploratory screen. The reported p-values are not multiple-testing-adjusted and therefore do not authorize promotion.

## Sanity checks: known mechanisms collapse as expected

`POX -> FLIP` has zero unique instances after trusted P-O-X-opposite is removed. It is exactly the already-known priority branch, not a new mechanism.

`SOS -> FLIP` initially looks stable in gross aggregates, but much of it overlaps SSOS. After SSOS removal, its confirmation subset turns negative. It therefore fails the novelty test as a stable independent module and is preserved as an overlap/context case rather than promoted.

Those two results show that the novelty screen is actually separating mechanisms rather than merely renaming them.

## What this adds to the chain model

Phase 1 was not hiding only two special strings. It contains **reusable local grammar**:

- some modules favor continuation with the current exhaustion;
- some modules favor anti-continuation / opposite orientation;
- the same small module can appear inside many different longer chains;
- some lower-order apparent motifs disappear when a known higher-order setup is removed, while other modules remain independent;
- module identity and timing family are separate axes, which explains why long-chain elapsed-time families can recur while their exact state grammar changes.

This is consistent with the rolling/re-origin state-machine interpretation rather than one permanent origin or one universal chain template.
