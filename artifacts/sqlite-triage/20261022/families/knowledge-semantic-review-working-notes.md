## Independently reproduced dipole clock contradiction

All 54,042 stored stage-book vectors match the canonical caller assignment at
21,437 exact indexed native coordinates. Every assigned book arrived after the
stage-bin timestamp. Relative to the last complete same-instrument book known at
that timestamp, 45,879 stages differ in book state and 8,925 differ in midpoint;
671 of 862 paths have a different midpoint coupling. This is not an assertion
that the whole retained row was emitted before its inputs: actual row emission
remains the availability bound. It shows why stage labels cannot be used as the
book's observation or availability clock.

Stage zero is stamped at candidate birth but uses the opening-emission book.
Later completed-second stages use the first group in a later receive second.
Original paths, caller-assigned vectors, strictly past vectors, exact clocks,
cursor/ordinal coordinates, row hashes and all disagreements are retained in
`dipole-book-clock-audit-v1`. Midpoint coupling is not an executable return.
The canonical definition reference at `2ebb8ce8` is kept distinct from the
`db96f24f` execution checkout identity; exact payload agreement does not establish
byte identity of those code checkouts.

Event phase and ordinal stage are separate. The source defines raw event-phase
strata and octave bins for stage index. `DipoleStage` carries no event-phase
field. Phase reconstruction must use lawful runway/lineage transitions, with
actual emission/censoring retained, rather than assigning terminal phase to all
earlier stages. This remains open.
