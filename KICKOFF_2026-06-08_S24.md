## 2. KEY UNRESOLVED FINDING — the dipole quadratic collapses (confirm at scale)
On a small/imbalanced smoke sample the in-sample positive control did NOT reproduce the
reference convex `c=1.309, R^2=0.943`. The quadratic term collapses to `c~=0, r2~=1` in ALL
THREE standardization modes the runner prints, each for a different reason:
- `pool` (the S22 Standardizer): mean-centering forces win/lose centroids EXACTLY antiparallel
  -> `H_a == -H_b` -> `H_a^2 == -(H_a*H_b)`, tautological r2=1. **This is a latent issue in the
  ported core** (`dipole_trade.fit_trade_dipole` standardizes the full pool before centroids).
- `none` (raw, ~original): one large-scale feature dominates both projections -> `H_a ~= +H_b`.
- `scale` (divide by std, no centering — the principled fix): `b~=+1.06, c~=0, r2~=0.99` — still
  essentially linear, no genuine curvature.
