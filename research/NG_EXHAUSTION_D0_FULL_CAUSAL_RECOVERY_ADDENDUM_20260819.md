## Clock semantics

D0 does **not** use post-birth H for terminality because an exact-D0 outcome has no newly born descendant.

The D0 early causal clock is called `ROOT_AGE`:

- anchor = frozen root causal confirmation;
- checkpoint = root confirmation + ROOT_AGE;
- eligibility = checkpoint must remain strictly before the next canonical event `t0`;
- report actual lead to that next event;
- first pass = ROOT_AGE 0,1,2,3,4,5 seconds.

This is directly comparable to the D1 PRIOR side but must not be mislabeled as H.

If a model/target remains unresolved after the early ROOT_AGE pass, later root-age/survivorship checkpoints may continue under the same causal rule. They still are not H.
