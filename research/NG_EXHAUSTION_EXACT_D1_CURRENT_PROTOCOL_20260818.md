## Current D1 population rule

A valid exact D1 is an instance with `all_model_consecutive_positive_depth == 1` in the frozen Phase-1 lineage. **Every such instance is retained.**

No D1 is discarded because it is short, long, extreme-tail, directional, choppy, lower-return, negative under one reference horizon, rare, low-support, or a true/false investigator case. Profitability is a ranking/annotation dimension only.

The campaign's purpose is to learn **how profitable each D1 type is and how that profitability varies with time length, causal runway, grammar, ancestry, path shape, and regime**, not to define D1 membership by profit.
