# Frankie metacognitive loop — isolated research/build agents

Two lanes ran: architecture research and specialist build/red-team.

The bounded prototype is post-evidence only. It binds hypothesis, first-lock, evidence, result, and path-trace artifacts; preserves every case/chain; and permits only next-run revision proposals.

For specialists A-E, the design is two-level: each specialist performs a local post-reveal audit without role/data changes, then Frankie reconciles shared assumptions, disagreements, missing evidence, and proposed discriminating tests. Agreement is not treated as truth and majority vote cannot erase minority evidence.

No V4 empirical workflow, five-year archive job, protected spawner, specialist role text, frozen detector/runway, or permanent brain was touched by these agents.
