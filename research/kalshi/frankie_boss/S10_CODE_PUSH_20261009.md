## The parent's sequence

1. `git push` the fix (the commit must be in the session clone; its tree objects must be local).
2. Base = the commit the box has staged (the newest staged checkout's commit, e.g. from the last PUSH_RECEIPT).
   `python3 deploy/aws/box/frankie_box_push_bundle.py build --commit <sha> --base <base sha> > pin.json`
   (omit `--base`, or fall back to it when the base is not in the clone, for a full ~600 MB pack).
3. Upload `pin.path` to `s3://frankie-granite42-568968024170-us-east-1/readiness/20260923/code-push/<sha>/<pin.sha256>.pack`
   through the AWS connector (presigned PUT + curl -T from the session), then presign a GET (900 s).
4. `BUNDLE_URL='<GET>' python3 deploy/aws/box/frankie_box_push_bundle.py parameters --pin pin.json --output params.json`
   and send it: ssm SendCommand(InstanceIds=[i-035994afa8bdf66a5], DocumentName=AWS-RunShellScript,
   Parameters={commands:[<assignments + script>], executionTimeout:['900']}, TimeoutSeconds=900, Comment=...).
   Read the invocation's stdout for `PUSH_RECEIPT`; on `PUSH_REFUSED ... send BUNDLE_KIND=pack` redo step 2 without
   `--base`. The URL is a capability: it lives in params.json and the SSM command record only.
5. Hand runners `code_root` from the PUSH_RECEIPT (never `/opt/frankie-box/code/current`).
