## AWS and processing choices

Do not migrate the scientific loop to Batch, Glue, EMR, Lambda, Step Functions or another host as a presumed optimization. For the later authorized real E2E, reuse existing progress/probe and receipt records to distinguish calculation, serialization, projection, checkpoint, queue wait and I/O time, peak memory and bytes read/written. Therefore an I/O problem cannot be diagnosed from volume settings alone.
