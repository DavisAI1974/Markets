# NG shadow implementation checklist

1. [ ] **Saved-window decisions.** Read the verified October 18 books and trade links locally. Reuse the pinned predicates and fixed calibration artifacts. Emit all six rule families by side with exact source coordinates, input coverage and abstention reasons. Reconcile all 2,850 baseline decisions, all solo dispositions, stack eligibility including unknowns, and the three check groups in the [design](plan.md).
2. [ ] **Causality and outcomes.** Compare the same real prefix under different recorded suffix lengths and verify identical decisions through the shared decision boundary. Check equal-time ordering by cursor and fail closed on a discontinuity, stale adjacency or unreconciled print membership. Freeze the decisions before scoring and reconcile the original entry/exit and censoring results per row. Verify unchanged event identity when multiple rules fire.
3. [ ] **Register and queue.** After saved-window decision parity, materialize the versioned register and queue. Link every observed fixed and historical variant, including singletons and adverse cases. Verify a targeted recheck of the same moment adds a mechanics record while preserving the distinct market observation count. Log pending science entries with the input or definition needed to run them.
4. [ ] **October 3 comparison.** Obtain and verify the pinned October 3 tape before running that date. Carry both days' 13-data-point attachments and run the same discovery rules on each day. Keep separate per-session results and register recurring and day-specific variants from both. Complete before any simulator order.
5. [ ] **Simulation capture.** Record a short user-operated NGZ6 Replay sample with no order. Check which inputs the interface can verify, including displayed touch, prior touch, prints, timing and continuity. Preserve fields the UI cannot establish. Open a separate simulator ticket only after agreement on the exact variant trigger, order type, size and exit. Verify that the execution ledger can retain misses, rejects, partial fills and contradictions.
6. [ ] **Full flow and geometry.** Once verified native October 18 tape and prior calibration exist, fix the source and timing defects from the audit and pass a native-prefix leakage check. Run the frozen flow/algebraic candidates and preserve every unscorable case. Keep BuildMap as the workflow and evidence viewer. Preserve the full-flow prerequisites and holds by session.

The first implementation checkpoint is the offline saved-window run plus a decision-by-decision reconciliation receipt. Operator capture can proceed independently. Keep durable work in Git and use a repository-backed workspace without a dependency on C:, E:, or desktop copies.
