## Purpose

Separate **structural validity** from **entry timing** across the exhaustion program.

A valid exhaustion structure is not killed merely because it cannot be predicted or fully identified at the earliest possible instant. If it is already causally predictable and profitable at the earliest validated entry, keep that early entry. If it is not, preserve it and test whether it becomes actionable later while enough causal runway and cost-adjusted opportunity remain.

This protocol applies to exact D1 and all preserved higher-order D2-D5 structures. It extends the finalized Phase-2 research; it does not reopen or alter Phase 2.

## Entry hierarchy

For every D1-D5 setup or subfamily:

1. **Earliest validated entry wins.** If the setup is already causally identifiable/predictable with positive validated net expectancy at the normal earliest decision point, retain that entry. Never delay it merely to satisfy a survival rule.
2. **Fallback revival only when necessary.** If the setup is not sufficiently actionable early, find the first later causal knowability point and test survivorship/checkpoint entry from there.
3. **No forced trade.** If no causal checkpoint retains enough expected edge/runway after costs, keep the structure in research memory without inventing an execution rule.
