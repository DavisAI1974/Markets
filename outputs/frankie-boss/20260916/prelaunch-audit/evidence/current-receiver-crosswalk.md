## Status vocabulary

| status | meaning |
|---|---|
| BOUND_TO_INVENTORY_DOCUMENT | the layer's only source path is the feed-inventory markdown; a named defect, never DELIVERED |
| CENSUS_ABSENT | the member carrier cannot be measured because neither the result field census nor a bounded scan of the delivered member ledger is available; this is missing evidence, not an absent carrier |
| DEGENERATE_PROOF_SAME_AS_SUBJECT | the proof layer and the package it is meant to prove bind the same file identity; an explicitly accounted bootstrap condition that does not claim independent proof and clears when an independent receipt is bound |
| DELIVERED | a receipt row names this layer's carrier AND the carrier is present in the run (field census, lifecycle section rows or legacy rows); for static layers, a knowledge receipt row DELIVERED with files |
| NOT_APPLICABLE | the arm is not in the layer's group arms |
| NO_PRODUCER_FOUND | nothing in the ingestion path produces it; the record says what was searched |
| OUTPUT_FILED | his output ledger, named by an outputs receipt |
| OUTPUT_PENDING | his output ledger; not named by an outputs receipt |
| PRINCIPAL_STAMPED | the input clock is stamped by the principal's own named output ledger rather than produced by the ingestion path; this one computed status satisfies the input-accounting gate |
| PRODUCED_NOT_DELIVERED | a producer exists and no VERIFIED receipt covers this layer on this run |
| RECEIPTED_CARRIER_ABSENT | a VERIFIED receipt names this layer, and measured run evidence shows the cited carrier is not there - the receipt over-claims (a structural drop, or 0 rows on this run) |
| RECEIPTED_CARRIER_ABSENT_FROM_SCANNED_PREFIX | a VERIFIED receipt names this layer, but the cited member carrier was not found before a bounded ledger scan stopped; this is prefix evidence, not a full-ledger absence claim |
| SEALED_PROVEN | a sealed-absence proof with all_absent true covers the run |
| SEALED_UNPROVEN | no sealed-absence proof, or one that found a token |
| SHADOW_DISABLED | PROVISIONAL_SHADOW and nothing opts it in (D5) |
